# Python 零基础教程 · 从第一行代码开始

一个纯前端的 Python 学习平台，专门为**从没写过代码的人**设计：把 Python 入门到工程实战整理成 **10 个阶段 / 87 个知识点 + 综合实战**，
用"生活化类比 + 可运行示例 + 常见坑 + 自测"的方式，带你从安装 Python、写下第一行代码开始，
一步步做出命令行小工具和 Web 后端接口；学有余力再走进阶选修，直通并发编程、调用 LLM、RAG、Tool Calling、Agent 等 **后端 + AI 应用开发**。

> 预计用时：认真学完约 **40 小时**（零基础节奏，数字只做参考，按自己速度来）。

## 快速开始

**Windows 用户（最省事）**：双击项目根目录的 **`启动学习.bat`**，它会自动启动开发服务器并打开浏览器。
具体行为：

- 服务已在运行 → 不重复启动，直接打开浏览器到 http://127.0.0.1:5173
- 首次运行（没有 `node_modules`）→ 自动先执行一次 `npm install`
- 其它情况 → 启动开发服务器，就绪后自动打开浏览器（端口被占用时打开实际端口）

关闭弹出的命令行窗口（或按 `Ctrl+C`）即停止服务。

**手机学习（扫码打开）**：开发服务器会同时监听局域网地址，并在终端打印一枚二维码：

```
  ──────────────────────────────────────────────────────────
  手机访问：手机与电脑连同一个 Wi-Fi，用相机 / 微信扫下方二维码打开
  http://192.168.1.5:5173/

  <二维码>

  手机打不开时：确认 Windows 防火墙允许 Node.js 访问"专用网络"，
  并确认电脑与手机在同一网段（公司网络 / 访客 Wi-Fi 常会隔离设备）。
  ──────────────────────────────────────────────────────────
```

> 提示：课程主体是"读 + 动手敲"。浏览器里的代码块能看示例输出，但真要练手，请按 README 末尾或每个知识点里的"跟着做"，
> 在自己电脑上装好 Python 来敲。手机适合通勤时看讲解、复习。

手机与电脑连同一个 Wi-Fi，用相机 / 微信扫码即可打开（页面本身已做移动端适配：窄屏为抽屉式导航）。
`npm run preview` 预览构建产物时同样会打印二维码（端口 4173）。

**命令行启动**：

```bash
npm install       # 安装依赖（首次）
npm run dev       # 本地开发，默认 http://127.0.0.1:5173
```

其它命令：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器（Vite，端口 5173，同时监听局域网并打印手机扫码二维码） |
| `npm run build` | 构建生产版本到 `dist/`（`base: './'`，产物可直接静态托管） |
| `npm run preview` | 本地预览构建产物（端口 4173，同样支持手机扫码访问） |
| `npm run validate` | 校验全部内容数据（结构、字段、id 唯一性、quiz 答案、禁用其它编程语言等） |
| `npm run check` | `validate` + `build` 一起跑 |

> 需求：Node.js 18+。

## 功能一览

- **学习总览** `/`：当前任务优先的聚焦式首页——先显示“下一节该做什么”、为什么学、执行清单和继续按钮；
  整体进度、阶段路线与学习数据放在可展开的“完整路线”区域，避免首屏信息堆砌。
- **知识点页** `/lesson/:id`：统一结构 —— 难度星级（难度 / 重要度）→ 零基础提示 →
  1 它是什么 → 2 打个比方 → 3 术语卡 → 4 跟着做（可选）→ 5 代码示例 → 6 常见坑 → 7 小练习 → 8 自测 → 9 掌握情况。
- **代码块**：语法高亮、复制、编辑、重置、▶ 运行。浏览器内没有 Python 解释器，采用**模拟运行**：
  直接展示该示例的真实输出；编辑后提示需在本机运行。
- **自测**：选择题 / 判断题 / 代码题，提交后显示对错与解析，可"再做一次"。
- **综合实战** `/practice`：主线用纯标准库做一个"待办清单 + 纪念日倒计时"命令行小工具；
  进阶选修（需先学完主线）把能力包成 FastAPI 接口。
- **速查表** `/cheatsheet`：按"我想做什么"查 Python 写法的速查表（去空格 / 遍历列表 / 读文件 / 发请求等），点击条目展开详细解释。
- **通关页** `/finish`：已掌握清单（按阶段分组）、AI 学习路线、"开始 AI 应用开发 →"。
- **顶部搜索**：按知识点与速查表条目搜索（如`变量`、`字典`、`读文件`、`requests`、`装饰器`），点击跳转。
- **学习进度持久化**：完成章节、当前章节、自测成绩、最后学习时间、总学习时长全部存 `localStorage`，刷新不丢；
  顶栏设置与侧边栏都提供"重置学习进度"（带二次确认）。
- **手机访问**：开发/预览服务器启动时在终端打印局域网地址与二维码，手机扫码即可打开（详见"快速开始"）。
- **视觉**：浅色 / 深色主题可切换，暖陶土主色、暖灰表面与白底代码块；桌面 / 笔记本 / 平板 / 手机响应式，窄屏为抽屉式导航。
- **在线版**：本课程网站已部署在 Cloudflare —— https://python-speedrun.3356921908.workers.dev ，
  push 到 GitHub 后自动构建上线（部署流程见"部署上线"一节的知识点）。

## 课程路线（10 个阶段 · 87 节）

| 阶段 | 核心成果 |
| --- | --- |
| 第一阶段 · 认识 Python（9 节） | 安装环境、变量、类型、运算符、列表、判断、循环、分支循环实战、调试入门 |
| 第二阶段 · 常用的数据（9 节） | 字符串与格式化编码、元组、列表深化（切片/排序/拷贝）、字典与遍历嵌套、解包、推导式、集合 |
| 第三阶段 · 组织代码（9 节） | 函数基础与进阶、闭包与高阶函数、递归、异常、模块 / import、作用域、工具函数、Git |
| 第四阶段 · 认识"对象"（9 节） | class、self、方法、@property 与类方法/静态方法、继承、多态与鸭子类型、魔法方法、类设计实战 |
| 第五阶段 · 读文件与异常（7 节） | 文件读写、CSV 与 pickle、`with`、异常处理、日志、sqlite3 |
| 第六阶段 · 常用模块（8 节） | json、datetime、random、os/pathlib、命令行参数、argparse、pip 与虚拟环境、collections |

## 扩展内容

内容与渲染完全分离，新增知识点只改数据文件即可：

1. 在 `src/data/phase1.js` ~ `phase10.js` 对应数组里追加一个对象，字段规范见
   [`docs/content-schema.md`](docs/content-schema.md)。
2. 运行 `npm run validate` 校验（会检查必填字段、`id` 唯一性、星级范围、quiz 结构与答案下标等）。
3. 侧边栏、阶段统计、上一/下一节、搜索索引、通关页清单都会自动生效，无需改组件。

综合实战步骤改 `src/data/practice.js`；速查表条目改 `src/data/cheatsheet.js`（每条需唯一 `id`）。

## 技术栈

- **Vue 3**（`<script setup>`）+ **Vite 6**
- **Vue Router 4**（hash 模式，适配静态托管）
- **Pinia**（状态与 `localStorage` 持久化）
- **Element Plus**（仅使用 `ElMessage` / `ElMessageBox`；其余 UI 与代码高亮为自研，无额外高亮库）

## 说明与已知取舍

- **模拟运行**：浏览器无法执行 Python，代码块的"运行"展示预置的真实输出；若你在编辑区改过代码，
  会提示需在本机运行。这是刻意的取舍，避免引入 Pyodide 等大体积依赖。
- **学习时长**：页面可见且 5 分钟内有过交互才计入，避免挂机刷时长。
- **数据存储**：全部在浏览器本地，不涉及登录、后端与数据库。
- **不要双击 `dist/index.html`**：构建产物用 ES module 加载，`file://` 协议下会被浏览器拦截而白屏；
  要预览构建版本请用 `npm run preview`，或把 `dist/` 交给任意静态服务器托管。
- **部署**：路由使用 hash 模式（地址形如 `/#/lesson/decorators`），且 `base: './'`，可放到任意子路径下静态托管。
- **手机访问**：为支持扫码访问，开发/预览服务器改为监听所有网卡（`server.host: true` / `preview.host: true`），
  同一局域网内的其它设备都能打开该页面；仅在本地开发时生效，构建产物本身不受影响。
  终端二维码用半角块字符渲染（浅色模块 = 终端前景色、深色模块 = 终端背景色），
  默认深色终端方向正确；若你的终端是浅色主题，二维码会反色，直接用打印出的网址即可。
  `qrcode-terminal` 只在开发时使用（devDependencies），产物不含该依赖。
- **构建体积**：当前为便于使用，Element Plus 采用全量注册，`index` chunk 约 1.2 MB（已通过
  `chunkSizeWarningLimit` 关闭告警）。若在意体积，可改为按需引入 `ElMessage` / `ElMessageBox` 及其样式。
